TYRALIA ROLEPLAY - ÉCRAN DE CHARGEMENT

1) Héberge tous les fichiers de ce dossier sur un site HTTPS.
2) Ouvre l'URL publique pour vérifier que la page fonctionne.
3) Mets dans la configuration serveur :
sv_loadingurl "https://TON-SITE/index.html"
4) Redémarre le serveur.

Personnalisation :
- Messages : tableau tips dans script.js
- Textes : index.html
- Fond : remplace background.jpg en gardant le même nom.
